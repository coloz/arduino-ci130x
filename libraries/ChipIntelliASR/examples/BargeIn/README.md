# BargeIn

## 示例作用

本示例用于验证 AEC（回声消除）和语音打断。设备先播放一段较长的测试说明；
用户在播报过程中说出资源内的唤醒词或命令词，示例打印识别结果，并用该命令关联的
提示音立即打断测试音。

该示例应选择“标准离线 ASR + AEC/语音打断”或“CWSL + AEC/语音打断”算法配置。
没有 AEC 参考回采线路的硬件不能完成真实的播报中识别测试。

## 使用方法

1. 在 Arduino 的“工具 > 算法配置”中选择带 AEC/语音打断的配置。
2. 以 115200 波特率打开串口监视器。
3. 等待 ID `16` 的长测试音开始播放。
4. 播报过程中说“**小智小智**”或任一命令词。
5. 查看串口中的命令 ID、语义 ID、分数和文本，并确认响应音打断原测试音。
6. 在串口发送字符 `p` 可重新播放测试音。

## 资源说明

- `recursos/` 用于标准 ASR 和标准 ASR + AEC。
- `recursos/cwsl/` 是同一命令集的 CWSL/CWSL + AEC 副本。
- ASR/DNN 由 ci-service 按 CI1306（AC 模型 `V00864`）生成，同样适用于
  CI1303；CI1302 应重新生成使用 `V00923` 的 DNN 资源。
- TTS 使用“晓君-川话男声”，语音 ID `1`～`17` 为本示例资源新生成内容；
  ID `0` 保留官方短蜂鸣音。
