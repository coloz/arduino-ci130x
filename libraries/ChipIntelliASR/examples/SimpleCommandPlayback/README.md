# SimpleCommandPlayback

## 示例作用

本示例展示最小的“识别事件 + 异步提示音”流程。它注册启动、唤醒、唤醒超时和
“打开空调”命令处理器，并分别播放资源中的启动音、唤醒回复、超时提示和操作结果。
示例通过 `setWakeWordEnabled(true)` 显式开启默认关闭的唤醒词门控。

所有回调都由 `ChipIntelliASR.tick()` 在 Arduino `loop()` 中分发，不需要在回调中
阻塞等待音频播放完成。

## 使用方法

1. 以 115200 波特率打开串口监视器。
2. 启动后设备播放“空调语音控制已就绪”。
3. 说“**小智小智**”，设备回复“我在，请说”。
4. 在命令窗口内说“**打开空调**”，设备回复“好的，空调已打开”。
5. 若命令窗口超时，设备播放“有需要再叫我”。

## 资源说明

- `recursos/` 用于标准 ASR 和标准 ASR + AEC。
- `recursos/cwsl/` 是同一命令集的 CWSL/CWSL + AEC 副本。
- ASR/DNN 由 ci-service 按 CI1306（AC 模型 `V00864`）生成，同样适用于
  CI1303；CI1302 应重新生成使用 `V00923` 的 DNN 资源。
- TTS 使用“晓君-川话男声”，语音 ID `1`～`17` 为本示例资源新生成内容；
  ID `0` 保留官方短蜂鸣音。
