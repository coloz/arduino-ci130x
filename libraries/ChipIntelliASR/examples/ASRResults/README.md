# ASRResults

## 示例作用

本示例展示 ChipIntelliASR 的事件式识别接口：

- `onResult()` 记录每一条离线识别结果；
- `attachCommand()` 精确处理命令 ID `2`（“打开空调”）；
- `attachSemantic()` 按语义 ID `0x01E41983` 处理“关闭空调”；
- `tick()` 在 Arduino `loop()` 任务中非阻塞分发事件。

它适合用来确认命令 ID、语义 ID、识别文本和分数是否与自定义资源一致。

## 使用方法

1. 以 115200 波特率打开串口监视器。
2. 说“**小智小智**”进入命令窗口。
3. 说“**打开空调**”或“**关闭空调**”。
4. 查看串口输出的命令 ID、语义 ID、分数、文本和对应动作。

## 资源说明

- `recursos/` 用于标准 ASR 和标准 ASR + AEC。
- `recursos/cwsl/` 是同一命令集的 CWSL/CWSL + AEC 副本。
- ASR/DNN 由 ci-service 按 CI1306（AC 模型 `V00864`）生成，同样适用于
  CI1303；CI1302 应重新生成使用 `V00923` 的 DNN 资源。
- TTS 使用“晓君-川话男声”，语音 ID `1`～`17` 为本示例资源新生成内容；
  ID `0` 保留官方短蜂鸣音。
