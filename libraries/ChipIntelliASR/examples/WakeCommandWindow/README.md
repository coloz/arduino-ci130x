# WakeCommandWindow

## 示例作用

本示例展示唤醒后的有限命令窗口，以及通过
`ChipIntelliASR.keepAwakeFor()` 主动延长窗口。默认窗口为 10 秒；识别到
“打开空调”后会重新延长 10 秒，并播放对应提示音。

示例同时处理 SDK 启动、唤醒和超时事件，适合作为需要连续多轮离线命令的状态机基础。

## 使用方法

1. 以 115200 波特率打开串口监视器。
2. 说“**小智小智**”，设备进入 10 秒命令窗口。
3. 在窗口内说“**打开空调**”；设备播放结果并重新计时 10 秒。
4. 不再说命令时，窗口超时并播放“有需要再叫我”。

## 资源说明

- `recursos/` 用于标准 ASR 和标准 ASR + AEC。
- `recursos/cwsl/` 是同一命令集的 CWSL/CWSL + AEC 副本。
- ASR/DNN 由 ci-service 按 CI1306（AC 模型 `V00864`）生成，同样适用于
  CI1303；CI1302 应重新生成使用 `V00923` 的 DNN 资源。
- TTS 使用“晓君-川话男声”，语音 ID `1`～`17` 为本示例资源新生成内容；
  ID `0` 保留官方短蜂鸣音。
