# PromptControl

## 示例作用

本示例通过串口交互测试 ChipIntelliAudio 的主要接口，包括直接按语音 ID 播放、
按命令 ID/语义 ID/命令文本查找提示音、蜂鸣音、停止、音量和静音。

直接语音测试使用 ID `16` 的长音频，因此可以在播放中发送 `x`，直观验证停止功能；
命令、语义和文本测试都使用“打开空调”及其关联提示音。

## 使用方法

以 115200 波特率打开串口监视器，每次发送一个字符：

| 字符 | 操作 |
| --- | --- |
| `v` | 播放 ID 16 的长测试音 |
| `b` | 播放 1 声蜂鸣音 |
| `B` | 连续播放 3 声蜂鸣音 |
| `c` | 按命令 ID 2 播放“打开空调”的关联提示音 |
| `s` | 按语义 ID `0x01E41943` 播放同一提示音 |
| `t` | 按文本“打开空调”查找并播放提示音 |
| `x` | 停止当前提示音 |
| `+` / `-` | 音量增加/减少 10 |
| `m` | 切换静音状态 |

每次操作后会打印请求是否被接受、当前播放状态、音量和静音状态。

## 资源说明

- `recursos/` 用于标准 ASR 和标准 ASR + AEC。
- `recursos/cwsl/` 是同一命令集的 CWSL/CWSL + AEC 副本。
- ASR/DNN 由 ci-service 按 CI1306（AC 模型 `V00864`）生成，同样适用于
  CI1303；CI1302 应重新生成使用 `V00923` 的 DNN 资源。
- TTS 使用“晓君-川话男声”，语音 ID `1`～`17` 为本示例资源新生成内容；
  ID `0` 保留官方短蜂鸣音。
